# PC Slow Watch

כלי ל-Windows לאבחון האטה במחשב באמצעות מדדים מקומיים ודוח מסודר לניתוח AI.

## פרטיות

- האיסוף מתחיל רק אחרי לחיצה על "התחל איסוף".
- אין חיבור ל-AI ואין העלאה אוטומטית.
- נשמרים נתוני ביצועים מצטברים וקטגוריות כלליות של עומס, לא שמות משתמש, מחשב, תהליכים, קבצים, כתובות רשת, הקלדות, כותרות חלונות או היסטוריית גלישה.
- שמות תהליכים משמשים בזיכרון בלבד לשיוך לקטגוריה כללית; שמות ו-PID אינם נשמרים.
- הנתונים נשמרים תחת LOCALAPPDATA\PCSlowWatch ונמחקים אוטומטית לאחר 30 יום.
- יצוא ZIP נעשה רק בלחיצה על כפתור, וצריך להעלות אותו ל-AI ידנית.

## הפעלה

דרישות: Python 3.10 ומעלה עם Tkinter. בלחיצה ראשונה על run_windows.bat, התוכנה תנסה להתקין את psutil אם חסר; לשם כך נדרש אינטרנט בזמן ההתקנה בלבד.

1. הורד את תיקיית PCSlowWatch.
2. הפעל את run_windows.bat.
3. לחץ על "התחל איסוף".
4. כשהמחשב איטי, לחץ על "סמן שהמחשב איטי עכשיו".
5. לחץ על "הכן דוח ל-AI" כדי לייצר ZIP של שבעת הימים האחרונים.

אין צורך בהרשאות מנהל.

## מה נמדד

CPU, RAM, swap, קצב קריאה/כתיבה לדיסק, השהיית קריאה/כתיבה משוערת, פעילות דיסק משוערת, תעבורת רשת מצטברת, מקום פנוי בכונן המערכת וזמן פעולה. התוכנה גם מסמנת חציית ספי עומס.

הערה: פעילות הדיסק היא הערכה מחושבת ולא מדידה ישירה של Windows Active Time; הקטגוריות הן אומדן כללי. הכלי אינו מודד טמפרטורות חומרה.
